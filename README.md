# 환경 한눈에

에어코리아·한국수자원공사·부산광역시 공식 공공데이터를 한곳에서 조회하는 환경 대시보드입니다.

**공개 서비스:** https://jeongsooooo-creator.github.io/environment/

## 데이터

| 기관 | 서비스 | 화면 |
| --- | --- | --- |
| 한국환경공단 | 에어코리아 대기오염정보 | 부산 측정소별 PM₂.₅·PM₁₀·오존, 최근 시간별 초미세먼지 |
| 한국수자원공사 | 공업생활용수 수질 정보 | 정수장별 일간 탁도·pH·잔류염소, 최근 30일 추이 |
| 부산광역시 | 우리동네 수질 정보 조회 | 구·군과 검사지점별 pH·탁도·잔류염소·기관 수질상태 |

K-water는 일간 자료이며 최신 측정일이 오늘보다 이전일 수 있습니다. 부산 API에는 측정시각이 없으므로 조회 시각을 별도로 표시합니다. 부산 그래프는 같은 동코드의 검사지점을 비교하며 시간 추이가 아닙니다. 부산 API가 동 이름을 제공하지 않아 동코드를 표시합니다.

페이지가 열려 있으면 10분마다 다시 조회합니다. 서버는 대기·부산 수질 응답을 최대 5분, K-water 일간 수질을 최대 30분 재사용합니다. 별도 장기 기록 저장은 하지 않습니다. 결측값은 0으로 대체하지 않습니다.

## 구조와 빌드

Node.js 22 이상에서 별도 패키지 설치 없이 빌드할 수 있습니다.

```sh
npm run check
npm run build
```

- `src/index.html`: 반응형 한국어 화면
- `src/client-water.js`: 조회, 그래프, 표, CSV 내려받기
- `src/server.mjs`: 공식 API를 호출하는 서버와 비밀키 처리
- `build.mjs`: 화면과 서버를 하나의 Worker ES 모듈로 생성
- `dist/server/index.js`: 빌드 결과(생성 파일)

서버는 `fetch(request, env)`를 지원하는 Worker 런타임에서 실행합니다. `/api/air`, `/api/kwater`, `/api/busan`은 같은 서버에서 제공합니다. GitHub Pages는 정적 호스팅이므로 이 서버를 실행하지 않습니다.

## 배포

화면은 GitHub Pages의 main 브랜치 /docs 폴더에서 제공합니다. 데이터 조회 서버는 Sites에서 운영합니다. GitHub Pages 화면은 서버의 공개 API를 호출하며 인증키를 포함하지 않습니다. 서버는 이 GitHub Pages 출처에서의 교차 출처 조회를 허용합니다.

화면 수정 후 npm run build로 docs/index.html을 다시 생성하고 docs 폴더를 함께 커밋하면 Pages 화면이 갱신됩니다. 서버 소스를 수정한 경우에는 Sites 서버도 별도로 다시 배포해야 합니다.

호스팅 서버에는 다음 변수를 비밀 설정으로 등록해야 합니다. 실제 값은 저장소에 포함하지 않습니다.

- `AIRKOREA_SERVICE_KEY`
- `KWATER_SERVICE_KEY`
- `BUSAN_WATER_SERVICE_KEY`

`.env.example`은 변수 이름 안내용이며 빌드 과정은 이 파일에서 키를 읽지 않습니다. 서버에 등록한 비밀값은 브라우저로 전달하지 않습니다. 공개 방문자는 인증 없이 대시보드와 공개 조회 API에 접근합니다.
